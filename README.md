## Abstract

I am a third-year **Computer Science & Engineering** student at **KIIT Bhubaneswar**, working at the intersection of **full-stack web development** and **applied generative AI**. My work spans LLM applications, retrieval-augmented generation, agentic workflows, and deep learning for computer vision, supported by hands-on MERN experience.

I have shipped a client-facing React website as a freelance developer and trained TensorFlow models during back-to-back AI and ML internships. Each stage involved reading documentation that was, in fairness, mostly accurate.

## Engineering Principles

1. **Ground the model.** An LLM without retrieval is an eloquent guesser.
2. **Measure before optimising.** Intuition is a hypothesis, not a benchmark.
3. **Ship, then iterate.** A deployed prototype outranks a perfect plan in staging.
4. **Name things clearly.** Future me is a stakeholder, and has filed complaints.
